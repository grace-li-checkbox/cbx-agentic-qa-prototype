# Matter tools in AI Agent chat

PRD: not linked yet.

- **Create a matter.** An AI Agent lets users create a matter from a chat request. It asks for the details it needs, routes the matter to the right board and assignee, and links to the new matter.
- **Change a matter.** An AI Agent lets users change a matter in the same chat: reassign it, change its status, replace its description and add an internal note. It says what it changed.
- **Changes reach Matter Management.** Changes the agent makes appear in Matter Management.
