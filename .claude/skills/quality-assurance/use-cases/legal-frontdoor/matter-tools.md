# Matter tools in AI Agent chat

PRD: not linked yet.

A user can ask an AI Agent in chat to work with matters:

- **Create a matter.** The user describes a request. The agent asks for details it needs, such as the contract value, picks the board and the assignee from its routing table, makes the matter, and replies with a link to it.
- **Change a matter from the same chat.** The user can ask the agent to reassign the matter, move it to another status, replace its description, and add an internal note. The agent replies with what it changed.
- **See the changes in Matter Management.** The board shows the new assignee and status, and the matter page shows the description and the note in its conversation.
